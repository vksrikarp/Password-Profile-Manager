# Password-Profile-Manager
A python based project on Password and Profile management. Object Oriented Programming is used to implement this project.
1. Encapsulation, Abstraction and Inheritance are implemented in the Project.
2. Multi level Inheritance is implemented and no need to give any arguments while creating instance of class.
3. While loop runs until the user either exits the loop deliberately or logs out of the application.
4. User need to register and login to perform any action except for Exiting the loop.
5. Choose the option based on the choice from table.
6. Dictionary and List used to maintain the data set.
